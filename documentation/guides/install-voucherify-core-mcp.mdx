Run the Voucherify Core MCP on your machine so your AI client can read a Voucherify project. The client starts the published package with `uvx`.

The hosted server signs in with your Voucherify login. Read [Voucherify Core MCP](/guides/voucherify-core-mcp) for that setup. This page uses an application ID and token.

## Prerequisites

- An MCP client, such as Cursor, Claude Desktop, or Visual Studio Code.
- [UV installed](https://docs.astral.sh/uv/getting-started/). Restart the client after you install UV for the first time.
- A Voucherify server-side application ID and token. A separate pair for the MCP is recommended.

## Install the package

<Steps>
  <Step title="Open your MCP client">
    Open your MCP client.
  </Step>
  <Step title="Add the configuration">
    Add this snippet to the client's `mcp.json`. The file location depends on the client. The client-specific steps below list the path for Cursor, Claude Desktop, and Visual Studio Code.

    ```json
    {
      "version": 1,
      "mcpServers": {
        "voucherify-core-mcp": {
          "command": "uvx",
          "args": ["voucherify-core-mcp", "--transport", "stdio"],
          "env": {
            "VOUCHERIFY_APP_ID": "<app id>",
            "VOUCHERIFY_APP_TOKEN": "<app token>",
            "VOUCHERIFY_API_BASE_URL": "https://<regionId>.api.voucherify.io"
          }
        }
      }
    }
    ```
  </Step>
  <Step title="Add your credentials">
    Copy your Voucherify server-side application ID and token from **Project settings** into `mcp.json`.
  </Step>
  <Step title="Set the API base URL">
    Set `VOUCHERIFY_API_BASE_URL` to the API base URL of the project's cluster. For shared clusters:

    - Europe: `https://api.voucherify.io`
    - North America: `https://us1.api.voucherify.io`
    - Asia: `https://as1.api.voucherify.io`
  </Step>
  <Step title="Run the connection">
    Run the connection with the MCP server.
  </Step>
  <Step title="Start a conversation">
    Open a new chat to start your conversation.
  </Step>
</Steps>

The package is connected when a new chat can read the project for those credentials.

For the tools you can ask about, read [Core MCP tools and examples](/guides/voucherify-core-mcp-reference).

<Note>

To run the server from source, or to read the test scenarios, visit the [Voucherify Core MCP repository](https://github.com/voucherifyio/core-mcp/).

</Note>

## Client-specific setup

<Tabs>
  <Tab title="Cursor">
    <Steps>
      <Step title="Open MCP settings">
        Go to **Settings** > **Cursor Settings** > **MCP** > **Add new global MCP server**.
      </Step>
      <Step title="Paste the configuration">
        Paste the configuration above into `~/.cursor/mcp.json`. To limit the server to one repository, create `.cursor/mcp.json` in that project.
      </Step>
      <Step title="Start a conversation">
        Open a new chat to start your conversation.
      </Step>
    </Steps>

    For more details, read the [Cursor MCP docs](https://docs.cursor.com/context/model-context-protocol).

    <Note>
    Starting from Cursor 1.0, click <a href="https://cursor.com/en-US/install-mcp?name=voucherify-core-mcp&config=eyJlbnYiOnsiVk9VQ0hFUklGWV9BUFBfSUQiOiI8YXBwIGlkPiIsIlZPVUNIRVJJRllfQVBQX1RPS0VOIjoiPGFwcCB0b2tlbj4iLCJWT1VDSEVSSUZZX0FQSV9CQVNFX1VSTCI6Imh0dHBzOi8vPGNsdXN0ZXJJZD4uYXBpLnZvdWNoZXJpZnkuaW8ifSwiY29tbWFuZCI6InV2eCB2b3VjaGVyaWZ5LWNvcmUtbWNwIC0tdHJhbnNwb3J0IHN0ZGlvIn0%3D" target="_blank"><img src="https://cursor.com/deeplink/mcp-install-light.svg" alt="Add voucherify-core-mcp MCP server to Cursor" height="32" /></a> for instant installation.
    </Note>
  </Tab>
  <Tab title="Claude Desktop">
    <Steps>
      <Step title="Add the configuration">
        Paste the snippet above in the path for your operating system:

        - macOS: `~/Library/Application\ Support/Claude/claude_desktop_config.json`
        - Windows: `%APPDATA%\Claude\claude_desktop_config.json`
      </Step>
      <Step title="Restart the app">
        Restart Claude Desktop.
      </Step>
      <Step title="Start a conversation">
        Open a new chat to start your conversation.
      </Step>
    </Steps>

    For more details, read the [Claude Desktop docs](https://support.claude.com/en/articles/10949351-getting-started-with-local-mcp-servers-on-claude-desktop).
  </Tab>
  <Tab title="Visual Studio Code">
    <Steps>
      <Step title="Open MCP configuration">
        Open MCP User Configuration. To limit the server to one workspace, create `.vscode/mcp.json` in that workspace.
      </Step>
      <Step title="Configure the file">
        Configure `mcp.json` as in [Install the package](#install-the-package).
      </Step>
      <Step title="Run the MCP server">
        In `mcp.json`, click **Run** above `voucherify-core-mcp`.
      </Step>
      <Step title="Start a conversation">
        In a new chat, select `voucherify-core-mcp` in the tool list and start your conversation.
      </Step>
    </Steps>

    For more details, read the [Visual Studio Code MCP docs](https://code.visualstudio.com/docs/copilot/chat/mcp-servers).
  </Tab>
</Tabs>
