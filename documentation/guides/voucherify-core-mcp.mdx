Voucherify Core MCP connects an AI client to a Voucherify project through the Model Context Protocol (MCP). MCP is an open standard. The client is the application where the agent runs. The server tells the agent which read tools it can call.

The agent can read campaigns, promotion tiers, orders, products, vouchers, customers, and related data. Read tools leave campaigns, validation rules, and other project data unchanged. Calls from the hosted server and from the local package count toward your billing period. Read [API usage](/guides/voucherify-core-mcp-reference#api-usage).

Use the Core MCP when you are:

- Building an AI tool that needs data from Voucherify.
- Combining Voucherify with other MCP servers.
- Asking for campaign, customer, or voucher data in natural language.

## Two ways to connect

You can use a server Voucherify hosts, or run the published package on your machine. Both expose the same read tools.

### Remote server

Voucherify hosts the server. Your client connects over HTTPS. You sign in with your Voucherify login and select a project from the list. The server reads that project on later tool calls, including when the project is on another cluster.

Choose the address closest to you. Responses are slightly faster from a nearby region. Each address can reach a project on any cluster.

| Region | Server URL |
| --- | --- |
| Europe | `https://eu.mcp.voucherify.io/mcp` |
| United States | `https://us.mcp.voucherify.io/mcp` |
| Asia | `https://as.mcp.voucherify.io/mcp` |

Connect Cursor, Claude Code, or Codex in [Connect the remote Core MCP](/guides/connect-voucherify-core-mcp). Cursor's configuration includes the server's client metadata URL. Claude Code and Codex use the server URL and sign in through the client.

### Local package

Your client starts the `voucherify-core-mcp` package with `uvx`. You provide a server-side application ID, an application token, and the API base URL of the project's cluster. A separate application ID and token for the MCP is recommended.

Install it in [Install the local Core MCP](/guides/install-voucherify-core-mcp). You can use Cursor, Claude Desktop, or Visual Studio Code.

To run the server from source, or to read the test scenarios, visit the [Voucherify Core MCP repository](https://github.com/voucherifyio/core-mcp/).

## What the agent can read

You ask a question in the client. The agent calls one or more read tools and returns the result. A narrow question, such as one campaign summary, uses fewer API calls. A question about the best deals for a cart uses more. The client asks you to confirm a call before it runs.

The tool list, example prompts, and worked examples are in [Core MCP tools and examples](/guides/voucherify-core-mcp-reference).
