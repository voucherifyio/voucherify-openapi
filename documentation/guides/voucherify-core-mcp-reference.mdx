These are the read tools exposed by the Voucherify Core MCP, with example prompts and two worked conversations.

Connect a client in [Connect the remote Core MCP](/guides/connect-voucherify-core-mcp) or [Install the local Core MCP](/guides/install-voucherify-core-mcp).

## Tools

The tools are available under the permissions assigned to the account used to sign in or the APP ID and APP TOKEN used to connect the MCP.

| Tool | What it returns |
| --- | --- |
| `find_customer` | A customer's current status and profile, including collected loyalty points and eligibility for rewards. Look up by email, source ID, or Voucherify ID. |
| `get_campaign` | A campaign's details, including name, type, status, start and end dates, or other data. |
| `list_campaigns` | Campaigns, so you can see which are active, scheduled, or completed. |
| `get_campaign_summary` | A performance summary of ongoing campaigns, including a comparison with past activity, such as the previous week. |
| `get_promotion_tier` | The configuration of a promotion tier, such as reward levels or thresholds that determine customer benefits. |
| `qualifications` | A customer's eligibility for campaigns, promotions, or reward rules. |
| `get_best_deals` | The top 5 incentives for a customer and cart. |
| `list_products` | The product catalog, including pricing, availability, and categories. |
| `get_voucher` | A voucher's code, status, balance, and expiration date. |
| `estimate_loyalty_points` | An estimate of the points a customer earns in a legacy loyalty campaign for an order, through earning rules with the order-paid type. Identify the customer by ID, source ID, or email, and include the ordered items (name or ID, and quantity). |

<Note>

For the best results with `get_best_deals`, set the Application rule to **Partial** in the Voucherify dashboard: **Redemptions** > **Stacking rules**. Read [Stacking rules](/orchestrate/stacking-rules).

</Note>

<Info>

`estimate_loyalty_points` returns an estimate. When a campaign includes tiers, mappings, and several earning rules, the final calculation can differ. A customer may change tiers and earn more or fewer points.

</Info>

## API usage

The number of API calls made by the Voucherify MCP depends on your question. Complex queries, like get best deals for a given customer, will need more API calls, while simple questions can be limited to just a few or even one, like get campaign summary. The MCP client will ask for confirmation to make an API call.

The API calls made with the Voucherify MCP are included in your billing period.

## Best practices

Follow these best practices to get the best results from the Voucherify Core MCP.

<AccordionGroup>
  <Accordion title="Ask specific questions">
    - Use precise date ranges (for example "July 2025 redemptions") instead of vague prompts like "recent redemptions".
    - Describe exactly what you need: specific campaign names, product categories, or data types.
    - Broad requests (for example "all campaigns in the last 3 years") usually lead to unclear results.
  </Accordion>
  <Accordion title="Add more context if necessary">
    If results look off, reframe your query or try again. If the AI loops or repeats itself, redirect with a new question or start a new chat with a more detailed prompt.
  </Accordion>
  <Accordion title="Ask more questions">
    Once you've got an answer you like, ask the client to:

    - Suggest additional insights or next steps.
    - Explain how it reached its conclusions to help refine your future prompts.
  </Accordion>
  <Accordion title="Change model">
    If you're not satisfied with answers or the overall process, use a different AI model. Each model is trained on different data, has their own strengths, and is best suited for various tasks.
  </Accordion>
</AccordionGroup>

## Prompt examples

Use these prompt examples to get started with the Voucherify Core MCP.

<AccordionGroup>
  <Accordion title="Customer lookup">
    Find customer by email `tom@example.com` (or `source_id`, or `customer_id`). Return the ID, `loyalty_balance`, `active_vouchers`.
  </Accordion>
  <Accordion title="Segment analysis">
    Count total of customers in segment "VIP". List their basic details: name, email address, `source_id`. Turn the data into a CSV-friendly format.
  </Accordion>
  <Accordion title="List campaigns">
    List active campaigns with fields: ID, name, type, `start_date`, `end_date`.
  </Accordion>
  <Accordion title="Voucher details">
    Get voucher by code "BK-4829" and show: status, `redemption.count`, `redemption.limit`, `balance` (for gift or loyalty cards).
  </Accordion>
  <Accordion title="Campaign data">
    Get campaign "BK-Sept-20OFF" data: total budget, spent budget, redemption counts, and per-customer caps.
  </Accordion>
  <Accordion title="Top coupon campaign">
    Show the campaign with the most coupons generated. Return redemption data for this campaign.
  </Accordion>
  <Accordion title="Best performing campaign">
    Show me the best performing campaign in terms of number of successful redemptions. Return the budget - the total discount value that was applied.
  </Accordion>
  <Accordion title="Redemption aggregation">
    Get redemptions aggregated by day between 2025-09-01 and 2025-09-03 (timezone Europe/Warsaw).
  </Accordion>
  <Accordion title="Best deals with cart">
    Get best deals for a customer with this email address. They have these items in their cart: Voucherify T-shirt (SKU: VCH-TST-001, quantity: 1, price: 25 USD), Voucherify Mug (SKU: VCH-MUG-002, quantity: 2, price: 15 USD each). Suggest if there's anything they can do to get even better deals.
  </Accordion>
</AccordionGroup>
