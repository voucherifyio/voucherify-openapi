A loyalty card holds a member's points. Voucherify records a card activity when a card is created, when it is assigned to a member, and when that assignment is removed. It also records whether code generation for the card succeeds or fails. These events show what happens to each card over its lifetime.

These events can start a workflow. For how a member holds cards and points, see [Members: Overview](/api-reference/loyalty-v2-members-overview).
