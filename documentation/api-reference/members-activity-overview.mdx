A member is a customer enrolled in a loyalty program. Voucherify records a member activity when a member is created, updated, deleted, activated, or deactivated, or when a loyalty card is assigned to or unassigned from that member. These events show when enrollment and card assignments change.

These events can start a workflow. For how membership is scoped to a program and how members earn and spend points, see [Members: Overview](/api-reference/loyalty-v2-members-overview).
