An earning rule decides when members earn points or receive benefits. Voucherify records an earning rule activity when a rule is created, updated, deleted, activated, or deactivated, or when it is assigned to or unassigned from a program. These events show when that behavior changes.

These events can start a workflow. For how an earning rule defines triggers, conditions, and earnings, see [Earning rules: Overview](/api-reference/loyalty-v2-earning-rules-overview).
