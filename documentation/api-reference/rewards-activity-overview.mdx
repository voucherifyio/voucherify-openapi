A reward is what members redeem their points for. Voucherify records a reward activity when a reward is created, updated, deleted, activated, deactivated, or drafted, or when it is assigned to or unassigned from a program. These events show when the rewards a member can buy change.

These events can start a workflow. For how a reward defines its costs, validity, and refunds, see [Rewards: Overview](/api-reference/loyalty-v2-rewards-overview).
