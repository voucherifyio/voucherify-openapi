A loyalty program connects card definitions, earning rules, tier structures, and rewards into one customer-facing setup. Voucherify records a program activity when that program is created, updated, deleted, activated, or deactivated, and when one of those components is assigned, unassigned, or updated on the program.

These events can start a workflow. The same changes are listed by the program activity history endpoint. See [Programs: Overview](/api-reference/loyalty-v2-programs-overview) for how a program is built and which assignments it accepts.
