A benefit is granted to a member automatically when an earning rule's conditions are met. Voucherify records a benefit activity when a benefit is created, updated, deleted, or activated. These events show when the value members receive changes.

These events can start a workflow. For the benefit types and the rules that apply to each, see [Benefits: Overview](/api-reference/loyalty-v2-benefits-overview).
