The `PENDING_POINTS_CANCELED` event indicates that pending points were canceled on a Loyalty v2 card.

<Note>This page documents only the event. If you need more details about the webhook payload data that includes this event, go to [Introduction to webhooks](/api-reference/introduction-to-webhooks "Introduction to webhooks v2024-01-01") page.</Note>

This event can trigger a workflow when **Loyalty transaction** is configured with the **Card transactions** group and the `PENDING_POINTS_CANCELED` transaction type. If the workflow reaches a **Webhook callout** action, Voucherify sends a webhook to the action's target URL.

The example shows the content of `data` for a transaction with the `APPROVED` status. A workflow can filter the trigger by transaction status. The matched status is available in `data.transaction.status`; it does not create a separate event type.

This event follows a `PENDING_POINTS_ADDED` transaction for the same pending points. Use the [Pending points added event](/api-reference/loyalty-transactions/card/pending-points-added).
