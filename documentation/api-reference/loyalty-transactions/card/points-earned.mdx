The `POINTS_EARNED` event indicates that points were credited to a Loyalty v2 card.

This event can trigger a workflow when **Loyalty transaction** is configured with the **Card transactions** group and the `POINTS_EARNED` transaction type. If the workflow reaches a **Webhook callout** action, Voucherify sends a webhook to the action's target URL.

The example shows the content of `data` for a transaction with the `APPROVED` status. A workflow can filter the trigger by transaction status. The matched status is available in `data.transaction.status`; it does not create a separate event type.

<Note>
This page documents the `data` object for `POINTS_EARNED`. See [Workflows webhooks](/api-reference/workflows-webhooks) for the shared webhook structure and the differences between Loyalty transaction and Loyalty activity payloads.
</Note>
