The `POINTS_EARNED` event indicates that points were credited to a Loyalty v2 card.

This event can trigger a workflow when **Loyalty transaction** is configured with the **Card transactions** group and the `POINTS_EARNED` transaction type. If the workflow reaches a **Webhook callout** action, Voucherify sends the payload shown on this page to the action's target URL.

The example shows a transaction with the `APPROVED` status. A workflow can filter the trigger by transaction status. The matched status is available in `data.transaction.status`; it does not create a separate event type.

<Note>
This page documents the `POINTS_EARNED` payload sent by Workflows. See [Workflows webhooks](/api-reference/workflows-webhooks) for the shared webhook structure and the differences between Loyalty transaction and Loyalty activity payloads.
</Note>
