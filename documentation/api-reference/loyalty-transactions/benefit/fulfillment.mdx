The `FULFILLMENT` event indicates that a Loyalty v2 benefit was fulfilled for a member.

<Note>This page documents only the event. If you need more details about the webhook payload data that includes this event, go to [Introduction to webhooks](/api-reference/introduction-to-webhooks "Introduction to webhooks v2024-01-01") page.</Note>

This event can trigger a workflow when **Loyalty transaction** is configured with the **Benefit transactions** group and the `FULFILLMENT` transaction type. If the workflow reaches a **Webhook callout** action, Voucherify sends a webhook to the action's target URL.

The example shows the content of `data` for a transaction with the `APPROVED` status. A workflow can filter the trigger by transaction status. The matched status is available in `data.transaction.status`; it does not create a separate event type.

Successful results nest the fulfillment effect under `data.transaction.details.result.details`.
