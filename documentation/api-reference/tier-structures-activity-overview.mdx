A tier structure sets the levels members can reach and the rule that decides which level a member qualifies for. Voucherify records a tier structure activity when a structure is created, updated, deleted, activated, deactivated, or drafted, or when it is assigned to or unassigned from a program. It also records when a tier in a structure is created, updated, or deleted.

These events can start a workflow. For how a tier structure qualifies members, see [Tier structures: Overview](/api-reference/loyalty-v2-tier-structures-overview).
