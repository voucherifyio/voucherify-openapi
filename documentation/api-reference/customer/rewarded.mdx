The `EVENTS.CUSTOMER.REWARDED` event indicates that a customer received a campaign reward. For **legacy loyalty**, this usually means the customer redeemed a reward in exchange for loyalty points. Referral campaigns can also emit this event when a referral reward is awarded.

This event is not used for Loyalty hub reward purchases. For those, use the [Purchase](/api-reference/loyalty-transactions/reward/purchase) and [Points spent on reward](/api-reference/loyalty-transactions/card/points-spent-on-reward) loyalty transaction events in [Workflows](/integrations/workflows).

This event is used in a webhook configured in Distributions in Voucherify dashboard.

<Note>This page documents only the event. If you need more details about the webhook payload data that includes this event, go to [Introduction to webhooks](/api-reference/introduction-to-webhooks "Introduction to webhooks v2024-01-01") page.</Note>
