The `EVENTS.CUSTOMER.REWARD_REDEMPTIONS.CREATED` event indicates that redemption of a reward has been created. For **legacy loyalty**, this usually follows a customer redeeming a campaign reward for points. Referral campaigns can also emit this event. It is not used for Loyalty hub reward purchases — use the [Purchase](/api-reference/loyalty-transactions/reward/purchase) and [Points spent on reward](/api-reference/loyalty-transactions/card/points-spent-on-reward) loyalty transaction events instead.

This event is used in a webhook configured in Project settings in Voucherify dashboard.

<Note>This page documents only the event. If you need more details about the webhook payload data that includes this event, go to [Introduction to webhooks](/api-reference/introduction-to-webhooks "Introduction to webhooks v2024-01-01") page.</Note>
