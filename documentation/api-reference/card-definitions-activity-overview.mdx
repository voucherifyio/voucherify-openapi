A card definition is the point wallet that loyalty cards are generated from. Voucherify records a card definition activity when a card definition is created, updated, deleted, activated, or drafted, or when it is assigned to or unassigned from a program. These events show when the setup of a point wallet changes.

These events can start a workflow. For how a card definition controls points, see [Card definitions: Overview](/api-reference/loyalty-v2-card-definitions-overview).
