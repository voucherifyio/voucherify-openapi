The `vl.tier_structure.unassigned` event indicates that a Loyalty v2 tier structure was unassigned from a program.

<Note>This page documents only the event. If you need more details about the webhook payload data that includes this event, go to [Introduction to webhooks](/api-reference/introduction-to-webhooks "Introduction to webhooks v2024-01-01") page.</Note>

This event can trigger a workflow when **Loyalty activity** is configured with the **Tier structures** group and the `vl.tier_structure.unassigned` activity type. If the workflow reaches a **Webhook callout** action, Voucherify sends a webhook to the action's target URL.

The example shows the content of `data`. It contains snapshots recorded with the activity. It is not wrapped in an `activity` property.

This operation also creates a separate `vl.program.tier_structure.unassigned` activity. Use the [Program tier structure unassigned event](/api-reference/loyalty-activity/programs/tier-structure-unassigned) to handle that event type.
