The `vl.tier_structure.tier.updated` event indicates that a tier in a Loyalty v2 tier structure was successfully updated in the dashboard or by [Update tier](/api-reference/tier-structures/update-tier), and by POST `/v2/loyalties/tier-structures/{tierStructureId}/tiers/batch` for each tier it updates.

<Note>
This page documents only the event data nested under `data`. See [Introduction to webhooks](/api-reference/introduction-to-webhooks) for the shared webhook structure, and [Workflows webhooks](/api-reference/workflows-webhooks) for the full Workflows webhook payload.
</Note>

This event can trigger a workflow when **Loyalty activity** is configured with the **Tier structures** group and the `vl.tier_structure.tier.updated` activity type. If the workflow reaches a **Webhook callout** action, Voucherify sends a webhook to the action's target URL.

The example shows the content of `data`. It contains snapshots recorded with the activity. It is not wrapped in an `activity` property.
