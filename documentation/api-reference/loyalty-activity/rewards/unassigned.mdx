The `vl.reward.unassigned` event indicates that a Loyalty v2 reward was unassigned from a program.

<Note>This page documents only the event. If you need more details about the webhook payload data that includes this event, go to [Introduction to webhooks](/api-reference/introduction-to-webhooks "Introduction to webhooks v2024-01-01") page.</Note>

This event can trigger a workflow when **Loyalty activity** is configured with the **Rewards** group and the `vl.reward.unassigned` activity type. If the workflow reaches a **Webhook callout** action, Voucherify sends a webhook to the action's target URL.

The example shows the content of `data`. It contains snapshots recorded with the activity. It is not wrapped in an `activity` property.

This operation also creates a separate `vl.program.reward.unassigned` activity. Use the [Program reward unassigned event](/api-reference/loyalty-activity/programs/reward-unassigned) to handle that event type.
