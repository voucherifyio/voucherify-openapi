The `vl.member.card.unassigned` event indicates that a Loyalty v2 card was unassigned from a program member.

<Note>This page documents only the event. If you need more details about the webhook payload data that includes this event, go to [Introduction to webhooks](/api-reference/introduction-to-webhooks "Introduction to webhooks v2024-01-01") page.</Note>

This event can trigger a workflow when **Loyalty activity** is configured with the **Members** group and the `vl.member.card.unassigned` activity type. If the workflow reaches a **Webhook callout** action, Voucherify sends a webhook to the action's target URL.

The example shows the content of `data`. It contains member, card, card assignment, and program snapshots recorded with the activity. It is not wrapped in an `activity` property.
