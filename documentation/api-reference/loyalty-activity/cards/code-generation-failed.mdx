The `vl.card.code_generation.failed` event indicates that Voucherify could not generate or assign a code to a Loyalty v2 card. The failure reason is available in `data.result.details`.

This activity is recorded later for a card created in the dashboard, or by [Create program member](/api-reference/programs/create-program-member), or by the batch scheduled with [Batch create program members](/api-reference/programs/batch-create-program-members).

<Note>
This page documents only the event data nested under `data`. See [Introduction to webhooks](/api-reference/introduction-to-webhooks) for the shared webhook structure, and [Workflows webhooks](/api-reference/workflows-webhooks) for the full Workflows webhook payload.
</Note>

This event can trigger a workflow when **Loyalty activity** is configured with the **Cards** group and the `vl.card.code_generation.failed` activity type. If the workflow reaches a **Webhook callout** action, Voucherify sends a webhook to the action's target URL.

The example shows the content of `data`. It contains snapshots recorded with the activity. It is not wrapped in an `activity` property.

`data.card.code` is normally `null`. It can contain an existing code when assignment fails because the card already has a code.
