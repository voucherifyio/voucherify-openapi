The `vl.card.code_generation.succeeded` event indicates that Voucherify successfully generated and assigned a code to a Loyalty v2 card. The generated value is available in `data.card.code`.

<Note>This page documents only the event. If you need more details about the webhook payload data that includes this event, go to [Introduction to webhooks](/api-reference/introduction-to-webhooks "Introduction to webhooks v2024-01-01") page.</Note>

This event can trigger a workflow when **Loyalty activity** is configured with the **Cards** group and the `vl.card.code_generation.succeeded` activity type. If the workflow reaches a **Webhook callout** action, Voucherify sends a webhook to the action's target URL.

The example shows the content of `data`. It contains snapshots recorded with the activity. It is not wrapped in an `activity` property.

This event follows the card creation and assignment activities recorded during member enrollment, whose card snapshots contain only `code: null` while code generation is pending.
