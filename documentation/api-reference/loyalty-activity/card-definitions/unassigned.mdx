The `vl.card_definition.unassigned` event indicates that a Loyalty v2 card definition was successfully unassigned from a program in the dashboard or by [Delete program](/api-reference/programs/delete-program) for each card-definition assignment, and by [Batch assign/unassign card definitions](/api-reference/programs/batch-assign-unassign-card-definitions) for each card definition it unassigns.

<Note>
This page documents only the event data nested under `data`. See [Introduction to webhooks](/api-reference/introduction-to-webhooks) for the shared webhook structure, and [Workflows webhooks](/api-reference/workflows-webhooks) for the full Workflows webhook payload.
</Note>

This event can trigger a workflow when **Loyalty activity** is configured with the **Card definitions** group and the `vl.card_definition.unassigned` activity type. If the workflow reaches a **Webhook callout** action, Voucherify sends a webhook to the action's target URL.

The example shows the content of `data`. It contains snapshots recorded with the activity. It is not wrapped in an `activity` property.

This operation also creates a separate `vl.program.card_definition.unassigned` activity. Use the [Program card definition unassigned event](/api-reference/loyalty-activity/programs/card-definition-unassigned) to handle that event type.
