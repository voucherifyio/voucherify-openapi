The `vl.card_definition.deactivated` event indicates that a Loyalty v2 card definition was deactivated.

<Note>This page documents only the event. If you need more details about the webhook payload data that includes this event, go to [Introduction to webhooks](/api-reference/introduction-to-webhooks "Introduction to webhooks v2024-01-01") page.</Note>

<Warning>This activity type is available as a workflow filter, but Voucherify does not currently emit it. Moving an active card definition back to draft emits [`vl.card_definition.drafted`](/api-reference/loyalty-activity/card-definitions/drafted) instead.</Warning>

You can select this activity type when **Loyalty activity** is configured with the **Card definitions** group, but it does not currently start workflow runs.

The example shows the content of `data`. It contains snapshots recorded with the activity. It is not wrapped in an `activity` property.
