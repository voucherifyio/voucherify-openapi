The `vl.program.earning_rule.unassigned` event indicates that a earning rule was unassigned from a Loyalty v2 program.

<Note>
This page documents only the event data nested under `data`. See [Introduction to webhooks](/api-reference/introduction-to-webhooks) for the shared webhook structure, and [Workflows webhooks](/api-reference/workflows-webhooks) for the full Workflows webhook payload.
</Note>

This event can trigger a workflow when **Loyalty activity** is configured with the **Programs** group and the `vl.program.earning_rule.unassigned` activity type. If the workflow reaches a **Webhook callout** action, Voucherify sends a webhook to the action's target URL.

Workflows send this activity in `data.trigger`.

This operation also creates a separate `vl.earning_rule.unassigned` activity. Use the [Earning rule unassigned event](/api-reference/loyalty-activity/earning-rules/unassigned) to handle that event type.
