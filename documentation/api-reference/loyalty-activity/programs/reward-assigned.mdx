The `vl.program.reward.assigned` event indicates that a reward was assigned to a Loyalty v2 program.

<Note>This page documents only the event. If you need more details about the webhook payload data that includes this event, go to [Introduction to webhooks](/api-reference/introduction-to-webhooks "Introduction to webhooks v2024-01-01") page.</Note>

This event can trigger a workflow when **Loyalty activity** is configured with the **Programs** group and the `vl.program.reward.assigned` activity type. If the workflow reaches a **Webhook callout** action, Voucherify sends a webhook to the action's target URL.

The example shows the content of `data`. It contains snapshots recorded with the activity. It is not wrapped in an `activity` property.

This operation also creates a separate `vl.reward.assigned` activity. Use the [Reward assigned event](/api-reference/loyalty-activity/rewards/assigned) to handle that event type.
