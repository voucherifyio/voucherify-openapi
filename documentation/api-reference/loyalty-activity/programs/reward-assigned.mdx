The `vl.program.reward.assigned` event indicates that a reward was successfully assigned to a Loyalty v2 program in the dashboard or by [Create program](/api-reference/programs/create-program) for each reward in the body, and by [Batch assign/unassign rewards](/api-reference/programs/batch-assignunassign-rewards) for each reward it assigns.

<Note>
This page documents only the event data nested under `data`. See [Introduction to webhooks](/api-reference/introduction-to-webhooks) for the shared webhook structure, and [Workflows webhooks](/api-reference/workflows-webhooks) for the full Workflows webhook payload.
</Note>

This event can trigger a workflow when **Loyalty activity** is configured with the **Programs** group and the `vl.program.reward.assigned` activity type. If the workflow reaches a **Webhook callout** action, Voucherify sends a webhook to the action's target URL.

Workflows send this activity in the `data.trigger` object.

This operation also creates a separate `vl.reward.assigned` activity. Use the [Reward assigned event](/api-reference/loyalty-activity/rewards/assigned) to handle that event type.
