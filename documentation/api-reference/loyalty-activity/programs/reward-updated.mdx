The `vl.program.reward.updated` event indicates that a reward assignment in a Loyalty v2 program was updated.

<Note>This page documents only the event. If you need more details about the webhook payload data that includes this event, go to [Introduction to webhooks](/api-reference/introduction-to-webhooks "Introduction to webhooks v2024-01-01") page.</Note>

This event can trigger a workflow when **Loyalty activity** is configured with the **Programs** group and the `vl.program.reward.updated` activity type. If the workflow reaches a **Webhook callout** action, Voucherify sends a webhook to the action's target URL.

Workflows send this activity in `data.trigger`.
